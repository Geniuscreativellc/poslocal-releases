# Descargas de Poslocal

Aquí se publican los instaladores de la app de escritorio de Poslocal y la información que la app y la página de descargas leen para saber cuál es la versión más reciente. No hay código en este repositorio.

Para instalar Poslocal, visita [poslocal.com/descargar](https://poslocal.com/descargar).

## Qué hay aquí

| Ruta | Para qué sirve |
| --- | --- |
| `stable/latest.json` | La versión estable más reciente. |
| `beta/latest.json` | La versión beta más reciente. |
| `history.json` | Todas las versiones publicadas, con sus novedades. |
| [Releases](../../releases) | Los instaladores de cada versión. |

## Sistemas

- **macOS** 11 o posterior: un `.dmg` para Mac con Apple Silicon o Intel.
- **Windows** 10 y 11: un instalador que no pide permisos de administrador, y una variante que funciona sin internet.
- **Linux**: `.deb` y AppImage.

## Verificación

Cada actualización que la app descarga va firmada con la llave de Poslocal, y la app la descarta si la firma no coincide. Cada versión lista además el SHA-256 de sus instaladores.
